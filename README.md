# VERDE — городская оранжерея

Готовый мини-магазин комнатных растений на Django: адаптивная витрина, поиск и категории, карточки растений, корзина, оформление заказа, подписка на новости и панель администратора.

## Запуск в Windows

Самый простой способ — запустить `start.bat`. Он создаст виртуальное окружение, установит Django, подготовит базу и откроет сайт по адресу `http://127.0.0.1:8000/`.

Или выполните команды вручную в этой папке:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_catalog
python manage.py runserver
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Панель управления

Создайте администратора:

```powershell
python manage.py createsuperuser
```

Админка находится на [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/). Через неё можно менять ассортимент, остатки, цены и статусы заказов, а также смотреть подписчиков.

## Что уже работает

- Каталог с поиском, категориями и сортировкой.
- Подробные страницы растений с рекомендациями по уходу.
- Корзина на сессиях с контролем доступного остатка.
- Форма доставки, создание заказа в базе и уменьшение остатков.
- Подписка на новости с проверкой и защитой от повторной регистрации адреса.
- Стартовый ассортимент из восьми растений — команду `seed_catalog` можно запускать повторно.
- Адаптивная вёрстка для телефона, планшета и большого экрана.

## Стек и настройка

- Python 3.10+
- Django 5.1
- SQLite
- HTML, CSS и ванильный JavaScript

Фотографии загружаются с Unsplash, Google Fonts — с Google Fonts, поэтому для них нужен интернет. Перед публикацией в интернете задайте собственный `SECRET_KEY`, выключите `DEBUG`, настройте `ALLOWED_HOSTS`, HTTPS и хранилище базы данных.

Оформление заказа сохраняет заявку и контакты в Django admin. Подключение реального эквайринга и оплаты картой в этот мини-проект не входит.
